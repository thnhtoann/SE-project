# Branch naming

- Format: `<type>/<short-description>`, lowercase, words separated by hyphens (e.g. `feature/database`, `fix/entrypoint-crlf`).
  - `type`: matches the commit types in [commit-messages.md](commit-messages.md) — `feature`, `fix`, `refactor`, `test`, `docs`, `chore`.
  - `short-description`: 2-4 words, the app/area or subject — no issue numbers unless the description would otherwise be ambiguous.
- Branch off `main`; open a PR back into `main` when ready for review.
- `.claude/worktrees/`-managed branches (`worktree-*`, auto-generated by the worktree tool) are exempt from this convention.
